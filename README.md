# Series Recommendation Application 🎬📺

แอปพลิเคชันสำหรับแนะนำและรวบรวมข้อมูลซีรีส์ แบ่งตามหมวดหมู่ (จีน, เกาหลี, ตะวันตก) พร้อมระบบจัดการสำหรับ Admin และระบบใช้งานสำหรับ User

---

## ✨ ฟีเจอร์หลัก (Key Features)

### สำหรับผู้ใช้งาน (User)
- **ระบบสมาชิก**: สมัครสมาชิก และเข้าสู่ระบบ
- **สำรวจซีรีส์**: เลือกดูซีรีส์ตามหมวดหมู่ (Series Chinese, Series Korean, Series Western)
- **รายละเอียดซีรีส์**: ดูข้อมูลโดยละเอียด เช่น เรื่องย่อ, จำนวนตอน, แพลตฟอร์มที่ฉาย, และรายชื่อนักแสดง
- **ระบบคอมเมนต์**: สามารถแสดงความคิดเห็นในซีรีส์แต่ละเรื่องได้

### สำหรับผู้ดูแลระบบ (Admin)
- **จัดการข้อมูลซีรีส์**: เพิ่ม, แก้ไข, และลบข้อมูลซีรีส์ในแต่ละหมวดหมู่ (CRUD Operations)
- **จัดการผู้ใช้งาน**: ตรวจสอบข้อมูลผู้ที่สมัครสมาชิก
- **จัดการคอมเมนต์**: ดูและจัดการความคิดเห็นจากผู้ใช้งาน

---

## 🚀 เทคโนโลยีที่ใช้ (Tech Stack)

### Frontend
- **Flutter**: พัฒนาส่วนติดต่อผู้ใช้ (UI) ทั้งในส่วนของ User และ Admin
- **http**: สำหรับเชื่อมต่อกับ REST API
- **shared_preferences**: สำหรับการเก็บข้อมูล Login เบื้องต้นในเครื่อง

### Backend
- **Node.js (Express)**: พัฒนา RESTful API
- **MySQL (mysql2)**: ระบบฐานข้อมูล
- **CORS**: รองรับการเชื่อมต่อจาก Frontend
- **Dotenv**: จัดการ Environment Variables
